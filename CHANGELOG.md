# Changelog

All notable changes to **NoteFlow** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- CLI with `new`, `list`, `search` and `serve` subcommands
- Auto-tagging from a keyword → tag map in `config.json`
- Web reader with rendered Markdown and syntax-highlighted code
- Tag filtering and search with matches highlighted inside the rendered note
- Five sample notes covering DSA, Flask, git, Docker and SQL
- Next.js landing page on the same site, linking straight to the live notes
